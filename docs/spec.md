# 力学的エネルギー保存則 立式トレーニングアプリ 仕様書 v2

改訂：2026-09-26（4.1 を 2026-09-28 追記）（v1 は [spec-v1.md](spec-v1.md)。変更点の一覧は末尾の付録）

## 1. 背景・目的

- 力学的エネルギー保存則の「立式」の定着が芳しくなく、紙のプリント（20問・2分・相互採点）を帯活動として反復実施してきた。
- 目的は次の3つ。
  1. 同じ問題を繰り返し効率的に処理し、立式のパターンを自動化すること。
  2. 記録を可視化し、生徒自身の意欲を喚起すること。
  3. **ゲーム感覚で続けたくなる仕組み**（タイムアタック・称号・図鑑）で、反復を習慣にすること。
- Googleフォーム（選択式）では「二乗か」「符号は」を選択肢から探す作業に認知負荷がかかり、本質的な訓練（状況→式の構成）にならなかった。この反省から、**生成的な操作を保ったまま自動採点する**。

## 2. 訓練対象

### 2.1 鍛えるスキル
状況（文章＋図）から、はじめ・あとの式に **どの項が生き残るか** を素早く判断し、並べる力。

### 2.2 鍛えないスキル（意図的に除外）
- 公式そのものの想起（`½mv²` を `½mv` と書くなど、次元を誤るレベルの誤答）
- 数値代入・計算処理
- 選択肢からの視覚探索

→ 誤った次元の式は画面に存在させない。

## 3. 問題

### 3.1 出題パターン（項の生死による分類）

記号：K=½mv²（運動）、U=mgh（重力による位置）、E=½kx²（弾性力による位置）

| ID | 場面 | はじめ | あと | ねらい |
|---|---|---|---|---|
| A1 | 静止から落下・地面着地（基準面=地面） | U | K | 最基本 |
| A2 | 投げ下ろし | K+U | K | 初速ありでKが生きる |
| A3 | 投げ上げ・最高点（基準面=手） | K | U | 向きが変わっても同型 |
| A4 | 落下の途中の高さ | U | K+U | あとに2項残る |
| A5 | 斜方投射の最高点 | K | K+U | 最高点でもKは消えない（罠） |
| A6 | 振り子・最下点 | U | K | A1と同型に気づく |
| A7 | なめらかな斜面をすべる | U | K | 角度は式に出ない |
| A8 | 基準面を途中にとる | U | K+(−U) | 位置エネルギーが負（罠） |
| B1 | ばねを縮めて放す・自然長通過 | E | K | 重力が出てこない |
| B2 | 物体がばねを押し縮めて静止 | K | E | B1の逆向き |
| B3 | ばね・自然長の手前 | E | K+E | あとに2項 |
| C1 | 鉛直ばねに乗せて放す・最下点 | U | E | Kが両端で消える（罠） |
| C2 | ばね発射・最高点（鉛直） | E | U | 3項のうちKだけ消える |
| C3 | ばね発射・途中 | E | K+U | 3項すべて登場 |
| D1 | 摩擦のある面 | — | — | 保存則が使えないと判断する |

### 3.2 本番セット（20問固定）

- 問題は **全体で20問の固定セット**。各問題に固定の番号 **No.1〜20** を付け、配布プリントと一致させる。
- アプリでは出題順をシャッフルするが、画面には常に No. を表示する（プリントと照合できる）。
- **前半（No.1〜10）／後半（No.11〜20）** は、それぞれ単独で10問コースとして成立する構成にする。

| | 前半 No.1〜10 | 後半 No.11〜20 |
|---|---|---|
| A群（5問） | A1・A3・A5・A6・A8 | A2・A4・A5・A7・A8 |
| B群（2問） | B1・B3 | B2・B3 |
| C群（2問） | C1・C2 | C1・C3 |
| D群（1問） | D1 | D1 |

- 罠のパターン（A5・A8・C1）は前半・後半の両方に入れる。
- 同型の組（A1・A6・A7）は前後半に分散させつつ、A1とA6は同じ前半に置いて「同じ形だ」と気づかせる。
- 文脈（ボール・人・台車・おもり等）は20問の中で混在させる。数値は入れない。条件の書き方は 4.1 の方針に従う。
- No. の並びは、群が固まらないよう混ぜる（プリントを上から解いても同じパターンが続かない）。

### 3.3 腕試しモード用の問題

| 区分 | 問題数 | 内容 | 状態 |
|---|---|---|---|
| 基礎 | 60問 | 本番と同じ15パターン・文脈違い（v1で作成した80問から本番20問を除いたもの） | 作成済み（要校閲） |
| 難関 | 30問程度 | 3.4の候補から | 次段階 |

- どちらも **10問ずつ** 出題する。基礎はパターン比率（A5・B2・C2・D1）を保ってランダムに抽出。
- 初見の問題で立式できるか（丸暗記になっていないか）を確かめる位置づけ。

### 3.4 難関問題の候補（次段階で仕様を確定）

| 候補 | 必要な拡張 |
|---|---|
| **C4（決定）** 鉛直ばねに取りつけた物体に、縮めた位置で上向きの初速を与え、ばねが最も伸びたところまで。基準面は自然長の位置 → K＋E＋(−U) ＝ E＋U | なし（K・U・Eで表現可） |
| 鉛直ばね・つり合いの位置を基準にとる | なし（K・U・Eで表現可） |
| 円運動の最高点（v≠0でKが残る） | なし |
| 2物体をつないだ運動 | K₁・K₂ など物体ごとのタイル |
| 摩擦がある場面で W＝ΔE の形にする | 非保存力の仕事 W のタイル（9章スコープ外の見直し） |

C4 の問題文（案）：
> 鉛直に立てたばねの上端に荷物を取りつけた。ばねを自然長から縮めた位置で、荷物に鉛直上向きの初速を与えた。荷物は上昇し、ばねが最も伸びたところで、高いところにいる人が受け取った。基準面は、ばねが自然長のときの荷物の位置。

- 荷物は「のせる」ではなく「取りつける」（のせただけでは自然長でばねから離れる）。
- 「押し上げる」ではなく「初速を与える」（手が仕事をし続けると保存則が成り立たない）。
- ねらい：両辺に E が残る／はじめの U が負／「最も伸びた」から v = 0 を読み取る。

## 4. 問題の提示形式

- **画面の上から「No.・問題文」→「図」→ 解答欄** の順に置く。
- 問題文は1〜2文の短文。数値は入れない。
- 図はパターンID（A1〜D1）ごとに1枚のテンプレートSVG。物体名だけを差し替える。
  - 基準面：破線＋ハッチング／物体：点または小さな四角／高さ：矢印＋記号（h など、数値なし）／初速：v₀ の矢印（与えた初期条件として描く）。あとの速さの矢印は描かない（位置と軌道の点線のみ）

### 4.1 条件の書き方（和文数訳は生徒の仕事）

物理特有の言い回しから式の条件を読み取る力（和文数訳）も訓練の対象とする。**言い回しから導く条件は、図にも文にも先回りして書かず、ヒントで問う。**

| 図・文に書いてよいもの | 図に書かない（ヒントで問う）もの |
|---|---|
| 基準面の位置 | 「静かに」「そっと」→ v₀ = 0 |
| 初期条件として与えるもの（投げたときの初速の矢印 v₀、「初速0で」など文中の明示） | 「最高点」→ v = 0（鉛直投げ上げ）／速度の鉛直成分 = 0（斜方投射） |
| | 「ばねが最も縮む」「伸びきる」→ v = 0 |
| | あとの速さの矢印 v（矢印の有無から K の有無を拾えてしまうため、すべて描かない） |
| 高さ h・縮み x などの位置関係、自然長の位置、面のなめらか／あらい | 「最下点」→ v = 0（鉛直ばね） |

- 問題文でも「一瞬止まった」「一瞬静止した」のような、条件をそのまま言い換えた表現は使わない（例：「ばねが最も縮んだ。」）。
- 図の高さは画面に合わせて縮め、**判定ボタンまでスクロールせずに届く** ことを優先する。

## 5. 解答UI（枠内スイッチ方式）

スマホ・タブレット・PCで同じ方式。画面幅に応じて配置だけ変える。

```
     U  =  K                       ← 式プレビュー
はじめ ［K］［U］［E］
あと   ［K］［U］［E］
［保存則は使えない］　［判定］
```

- 【はじめ】【あと】の各行に **K・U・E のスイッチ** を置く。押すと点灯して項が入り、再度押すと消える。**枠を選ぶ操作は不要**（どのスイッチも直接押せる）。
- **U だけは 消灯 → U → −U → 消灯** の3段階。独立した `−` のタイルは置かない。
- 点灯した項から **式プレビュー**（例：`K + U = K`、`U = K + (−U)`）を上に表示する。`+` は自動。
- D群用に **「保存則は使えない」** ボタン。
- 各スイッチには意味ラベル（運動エネルギー ½mv² など）を小さく併記する（設定で非表示可）。
- 行の高さは固定。項が2〜3個でも折り返さず、スクロールも発生させない。
- **配置**
  - スマホ（縦長）：上下2段。判定ボタンは画面下部に常に見える位置。
  - PC・横長：【はじめ】＝【あと】を横に並べ、判定ボタンをすぐ右に置く（マウス移動を最小に）。
- **キーボード**（PC・タブレット）

| キー | 動作 |
|---|---|
| `1` `2` `3`（`K` `U` `E`） | 選択中の行の K・U・E を切り替え |
| `4` / `=`（`Tab` `←` `→` も可） | 【はじめ】【あと】の行を切り替え |
| `Enter` / `Space` | 判定 |
| `0` / `N` | 保存則は使えない |
| `Backspace` | 選択中の行を空にする |
| `Esc` | 中断 |

- ドラッグ操作は採用しない（1項あたりの操作時間が長くテンポを損なう／タブレットでスクロールと競合する）。

## 6. モードと進行

### 6.1 モード

| モード | 記録 | タイマー | 問題 | コース |
|---|---|---|---|---|
| **本番** | 残る | あり（タイムアタック） | 本番セット | 前半10／後半10／通し20 |
| **練習** | 残らない | なし | 本番セット | 前半10／後半10／通し20 |
| **腕試し** | 残る（本番とは別枠） | あり（タイムアタック） | 基礎60・難関30 | 各10問ランダム |

- 腕試しは、本番で一定の称号（初期値：新幹線級）を得るか、先生がリンクで指定したときに解放する。

### 6.2 タイムアタック（本番・腕試し）

- 開始のカウントダウン後、タイマーは **0からカウントアップ**。制限時間はない。
- **全問に正解するまで終わらない**。1問ずつ正解してから次へ進む。
- 誤答時の流れ：

| | 表示 | 操作 |
|---|---|---|
| 1回目の誤答 | 画面フラッシュ＋効果音、**1.5秒操作不能**、ヒント（どちらの行が違うか＋問いかけ） | 考え直して再解答 |
| 2回目の誤答 | 1.5秒操作不能、**正答を表示** | 正答を自分で入力して次へ |

- 操作不能の時間もタイムに含まれる（ミスの重み）。
- 記録するのは **クリアタイム** と **ミス**（誤答した問題数・誤答回数）。

### 6.3 練習

- タイマーなし。コース内の全問を一周する。
- 誤答時の流れは本番と同じ（1回目：ヒント、2回目：正答を表示して入力）。ただし操作不能時間はない。
- 正解後に「解説を見る」で trap（解説）を確認できる。

### 6.4 結果画面（上から順に）

1. クリアタイム・ミス数・**称号**（新しい級に上がったときは演出＋その級の雑学を一言）
2. 次の級までの差（例：あと3.2秒で空気分子級）
3. **ミスした問題の一覧（No.順）**：No.・問題文・図・正解・自分の1回目の答え・解説
   → 下にスクロールしながら、配布プリントの同じ No. にメモを取る運用
4. 記録の推移グラフ（本番・腕試しのみ）
5. 結果コードのコピー／送信

### 6.5 その他

- ウォームアップ（K・U・Eの式を3つ選ぶ、5秒程度）：本番前に任意で挿入。タイムには含めない。
- コース内の出題順は毎回シャッフル。

## 7. 称号

### 7.1 称号ラダー（物理に関係する速さ・10級）

| 級 | 速さ（目安） | 雑学（獲得時に表示） | 10問 | 20問 |
|---|---|---|---|---|
| 導線中の電子級 | 約 0.1 mm/s | 電流はすぐ伝わるが、電子そのものはカタツムリより遅い | 完走 | 完走 |
| 歩く人級 | 約 1.3 m/s | 時速にすると約4.5 km/h | 120秒以内 | 240秒以内 |
| 雨粒級 | 約 9 m/s | 空気抵抗のおかげで、これ以上は速くならない（終端速度） | 98秒 | 195秒 |
| 人類最速級 | 約 12 m/s | 100 m走のトップスピードの瞬間 | 79秒 | 159秒 |
| 新幹線級 | 約 90 m/s | 時速320 km は秒速約90 m | 65秒 | 129秒 |
| 音速級 | 約 340 m/s | 気温が高いほど速くなる | 53秒 | 105秒 |
| 空気分子級 | 約 500 m/s | 常温の空気の分子は音速より速く飛び回っている | 43秒 | 85秒 |
| 第一宇宙速度級 | 約 7.9 km/s | 地面すれすれを回り続ける人工衛星の速さ | 35秒 | 70秒 |
| 原子の中の電子級 | 約 2200 km/s | 水素原子の電子は光速の約1/137 | 28秒 | 57秒 |
| **光速級** | 約 30万 km/s | 1秒で地球を7周半 | **23秒** | **46秒** |

- **ノーミス** でクリアした場合は称号に ★ を付ける（例：音速級★）。
- 称号は **コースごと**（前半・後半・通し・腕試し）に判定する。20問は同じ比で2倍にして計算する（端数の丸めで、10問の秒数のちょうど2倍と1秒ずれることがある）。腕試しの秒数は初見であることを考慮して別に設定できる（初期値：10問と同じ）。

### 7.2 時間区分の決め方

- **光速級 ＝「現実的に極めれば到達できる最速タイム ＋ 3秒」**。
  実装後、先生や速い生徒の最速タイムを測って決める（上表の23秒は「1問約2秒×10問＋3秒」の仮置き）。
- 教員が設定するのは **光速級の秒数と歩く人級の秒数（初期値120秒）の2つだけ**。その間の級は等比で自動的に割り振る。

### 7.3 称号図鑑（コンプリート要素）

- ホームから開ける一覧。10級 × ★の有無 ＝ 20マス。
- **未獲得の級は名前を伏せ（「？？？級」）、時間区分だけを小さく表示** する。獲得すると級名・速さ・雑学が現れる。
- 各マスには、どのコース（前・後・通・腕）で獲得したかを小さな印で示す。
- 紙の記録用紙（8.2）にも **時間区分の帯だけ** を印刷し、級名は空欄にする。獲得したら生徒が自分で書き込む。

## 8. 記録・保存

### 8.1 アプリ内の記録（localStorage）

- 本番・腕試しのみ記録する。練習は記録しない。
- 記録項目：実施日時、モード、コース（前半／後半／通し／腕試し基礎／腕試し難関）、クリアタイム、誤答回数、ミスした問題の No.（パターンID）、称号、★の有無、出席番号（任意）
- 紙の記録用紙をなくしたときの控え、兼 図鑑・グラフの元データ。

### 8.2 紙の記録用紙

- 印刷ページ（9章）から出力。縦軸＝タイム、横軸＝回数のグラフ枠。
- 縦軸に **時間区分の帯** を印刷（級名は空欄）。コースごとに1枚。
- 手で書くことで伸びを実感させ、机間指導でも確認できる。端末を共用していても困らない。

### 8.3 記録するモードかどうかの見分け

| | 本番・腕試し（記録する） | 練習（記録しない） |
|---|---|---|
| ホームのボタン | 色つきの大きいカード＋「記録されます」 | 白いカード＋「記録なし」 |
| 解答中の上部バー | 色つき（本番は青、腕試しは別色）＋大きなタイマー | 灰色＋「練習中・記録されません」を常時表示 |
| 開始時 | カウントダウンに「この結果は記録されます」 | カウントダウンなし |
| 結果画面 | 「記録しました（第12回）」＋称号 | 「練習（記録なし）」 |

### 8.4 書き出し・送信（段階的実装）

1. **localStorage のみ**（まずこの段階で運用）
2. **書き出し**：結果コード（1行テキスト）をコピーして Googleフォームに貼り付け／CSV保存
3. **GAS＋スプレッドシート**：`doPost` で追記。`Content-Type: text/plain` で送信し GAS 側で `JSON.parse`。個人識別は出席番号（メールアドレスは使わない）

### 8.5 評価への使い方についての注意

- 記録・称号は自己評価・振り返りの材料。**称号やタイムを評価に直結させない**（初期値を意図的に遅くする等の逆インセンティブを避ける）。
- 評価に用いる場合は「グラフを見て何を変えたか」の記述と組み合わせる。
- 次の段階（数値入りの文章題）へ移る目安は、先生が称号の一つを目標ライン（例：新幹線級★）として示す形で運用する。

## 9. 印刷ページ

アプリと同じ問題データから生成する（問題を直すとプリントも一致する）。A4縦。

1. **問題プリント**：No.1〜20、問題文＋図＋解答欄（はじめ＝あと）。前半・後半で表裏に分けられるレイアウト。
2. **解答プリント**：上記に正答と解説（trap）を付けたもの。
3. **記録用紙**：コースごとのグラフ枠と時間区分の帯（8.2）。

## 10. データ構造

### 10.1 パターン定義（patterns.json）

```json
"A5": {
  "name": "斜方投射の最高点",
  "start": ["K"],
  "end": ["K", "U"],
  "hint": {
    "start": "投げた点は基準面の上。高さはある？",
    "end": "斜めに投げた物体の最高点で、0になるのは速度の縦と横のどちら？",
    "notApplicable": "摩擦や空気抵抗は書かれている？"
  },
  "trap": "最高点でも水平方向の速さは残るので、Kは0にならない。"
}
```

- `hint`：1回目の誤答で出す **問いかけ型** のヒント。答えは書かず、言い回しを条件に訳させる（例：「ばねが最も縮むとき、速度は？」）。違っている行（start／end）に応じて出し分け、「使えない」を誤って選んだ場合は `notApplicable` を出す。
- `trap`：結果画面・練習の解説用。答えを含んでよい。
- 負の位置エネルギーは `"-U"`、D群は `"applicable": false`。

### 10.2 問題（questions.json）

```json
{ "no": 7, "set": "main", "half": 1, "id": "A5-1", "type": "A5", "label": "ボール",
  "text": "地面からボールを斜め上に投げ、ボールは最高点に達した。基準面は投げた点。" }
```

- `set`：`main`（本番20問）／`basic`（腕試し基礎）／`advanced`（腕試し難関）
- `no`・`half`：本番セットのみ。
- `start`・`end`・`hint`・`trap`・`diagram` はパターンから継承（問題側に書けば上書き）。
- 読み込み後の問題オブジェクトは v1 仕様書7章の形（`id, type, diagram, text, start, end, trap`）を含む。
