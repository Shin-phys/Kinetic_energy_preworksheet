## 2. 図と問題文の方針（2026-09-28 決定）

**「和文数訳」は生徒の仕事にする。** 物理特有の言い回しから式の条件を読み取る力も訓練の対象とし、図には先回りして書かない。

| 図・文に書いてよいもの | 図に書かない（ヒントで問う）もの |
|---|---|
| 基準面の位置 | 「静かに」「そっと」→ v₀ = 0 |
| 初期条件として与えるもの（投げたときの初速の矢印 v₀、「初速0で」など文中の明示） | 「最高点」→ v = 0（鉛直投げ上げ）／速度の鉛直成分 = 0（斜方投射） |
| | 「ばねが最も縮む」「伸びきる」→ v = 0 |
| | あとの速さの矢印 v（矢印の有無から K の有無を拾えてしまうため、すべて描かない） |
| 高さ h・縮み x などの位置関係、自然長の位置、面のなめらか／あらい | 「最下点」→ v = 0（鉛直ばね） |

- 図から「v = 0」の表示をすべて削除した（15枚とも）。
- あとの速さ v の矢印をすべて削除した。矢印の有無から K の有無を拾えないようにするため。動きの向きは軌道の点線で示す。
- 残る矢印は、与えた初期条件の v₀ だけ（A2・A3・A5・B2）。「投げた」「進んできた」と文に書いてあるものに限る。
- 問題文の「一瞬止まった」「一瞬静止した」も削除した（No.13 ほか、腕試し用の2問）。

## 3. ヒント（1回目の誤答で表示）

答えは書かず、**言い回しを条件に訳させる問いかけ** にする。違っている行（はじめ／あと）に応じて出し分け、両方違うときは両方を表示する。

| 型 | はじめが違うとき | あとが違うとき |
|---|---|---|
| A1 | 「静かに放す」とき、はじめの速度は？ | 基準面の上では、高さはいくつ？ |
| A2 | 投げ下ろした瞬間、速度はある？ 高さは？ | 基準面の上では、高さはいくつ？ |
| A3 | 投げた点は基準面の上。高さはある？ | 真上に投げたボールが最高点にきたとき、速度は？ |
| A4 | 「静かに放す」とき、はじめの速度は？ | 途中の点は、まだ基準面より上？ 速度は？ |
| A5 | 投げた点は基準面の上。高さはある？ | 斜めに投げた物体の最高点で、0になるのは速度の縦と横のどちら？ |
| A6 | 「静かに放す」とき、はじめの速度は？ | 最下点は基準面。そこでの高さは？ |
| A7 | 「静かにすべらせる」とき、はじめの速度は？ | 下端は基準面。斜面の角度は式に必要？ |
| A8 | はじめの位置は、基準面より上？ 下？ | 基準面より下の点で、位置エネルギーの符号は？ |
| B1 | 「静かに放す」とき、はじめの速度は？ ばねは縮んでいる？ | 自然長のとき、ばねのエネルギーは？ 高さは変わった？ |
| B2 | ばねに当たる前、ばねは縮んでいる？ | ばねが最も縮むとき、速度は？ |
| B3 | 「静かに放す」とき、はじめの速度は？ | 自然長の手前では、ばねはまだ縮んでいる？ |
| C1 | 「静かに放す」とき、はじめの速度は？ ばねは縮んでいる？ | 最下点（ばねが最も縮むところ）で、速度は？ 高さは？ |
| C2 | 放す位置は基準面。高さは？ 「静かに放す」ときの速度は？ | 真上に飛んだ物体の最高点で、速度は？ ばねから離れている？ |
| C3 | 放す位置は基準面。高さは？ 「静かに放す」ときの速度は？ | 途中の点では、ばねから離れている？ 高さと速度は？ |

**「保存則は使えない」に関するヒント**

| 場面 | ヒント |
|---|---|
| A〜C で「使えない」を選んだ | 摩擦や空気抵抗など、力学的エネルギーを減らすものは書かれている？ |
| D1 で式を作った | 面の様子をもう一度読もう。エネルギーが熱に変わる原因はない？ |
